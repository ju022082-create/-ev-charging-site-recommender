# EV 급속충전소 입지 추천 웹앱 (실제 데이터 기반 MVP)

## 실행
1. Python 3.10 이상 설치
2. 이 폴더에서 터미널 실행
3. `pip install -r requirements.txt`
4. `streamlit run app.py`
5. 자동으로 열리는 브라우저에서 이용

## 데이터
- 충전소: 한국환경공단 API 활용신청 https://www.data.go.kr/data/15076352/openapi.do
- API 인증키를 사이드바에 입력하고 불러오기 클릭. 인증키를 저장하거나 공유하지 마세요.
- 대안: 동일한 열 구조의 CSV/XLSX 업로드. 충전소 최소 필수 열은 `위도`, `경도`, `주소`; API 원본은 `lat`, `lng`, `addr`를 지원합니다. 급속충전기 필터에는 `출력` 또는 `output` 필요.
- 전기차 등록대수 CSV: `지역,전기차등록대수` (예: `전라남도 나주시,1234`)
- 교통량 CSV: `지역,일평균교통량` (예: `전라남도 나주시,56789`)
- 파일은 실제 조사한 수치만 입력하세요. 가상 수치를 입력하면 결과도 가상 분석입니다.
- 전국 모든 행정구역을 비교하려면 API의 모든 페이지를 충분히 수집해야 합니다. 기본 5페이지는 데이터 전체를 보장하지 않습니다.

## 방법론 및 한계
- 충전기 출력 50kW 이상을 급속으로 정의(프로젝트 가정).
- 충전기 개수를 지역별 집계하고 전기차 수요, 교통량, (전기차 수 / (급속충전기 수+1))을 최소-최대 정규화한 뒤 가중합.
- 데이터가 누락된 지역은 점수 계산에서 제외합니다.
- 지역 간 비교 점수는 분석에 포함된 지역의 범위에 따라 달라집니다.
- 교통량을 시군구별로 집계하는 방법(도로별 합산/대표값 등)은 팀에서 결정하고 명시해야 합니다. 단순 합계는 측정 지점 중복에 주의하세요.
- 충전소 API 데이터에 출력 열이 없으면 전체 충전기 수를 표시하며 급속충전기만 집계했다는 보장이 없습니다.
- 설치 후보지의 정확한 좌표가 아니라 행정구역 단위 우선순위를 보여주는 1차 버전입니다.
- 사용 전 API 제공처의 이용조건과 호출 제한을 확인하세요.
